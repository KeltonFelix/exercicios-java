# ☕ Exercícios em Java

Coleção de exercícios de **lógica de programação em Java**, desenvolvidos 
durante o curso de Desenvolvimento de Sistemas. Cobre desde variáveis 
básicas até orientação a objetos.

## 📂 Blocos de exercícios

| # | Bloco | Tema | Conceitos |
|---|-------|------|-----------|
| 01 | [Variáveis e Scanner](./01-variaveis-e-scanner/) | Entrada/saída e cálculos básicos | `int`, `double`, `String`, `Scanner` |
| 02 | [Condicionais](./02-condicionais/) | Estruturas de decisão | `if/else`, operadores lógicos |
| 03 | [Loops e Classes](./03-loops-e-classes/) | Repetição e orientação a objetos | `for`, `while`, classes, métodos, arrays |
| 04 | [Projeto Posto](./04-posto-combustivel/) | Exercício integrador | Combinação de condicionais e cálculos |

## 🧠 Conceitos praticados

### Básico
- Variáveis (`int`, `double`, `String`, `char`)
- Entrada com `Scanner`
- Saída formatada com `System.out.printf`
- Operadores aritméticos

### Intermediário
- Condicionais `if`, `else if`, `else`
- Operadores lógicos (`&&`, `||`, `!`)
- Laços `for` e `while`

### Avançado
- Métodos estáticos
- Classes e objetos (POO)
- Encapsulamento (`private`, getters e setters)
- Arrays e ordenação (`Arrays.sort`)
