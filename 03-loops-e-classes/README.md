# ☕ Exercícios em Java – Loops e Classes

Exercícios com foco em **estruturas de repetição** e **orientação a objetos**.

## 📘 Exercícios

| Arquivo | Descrição |
|---------|-----------|
| `Fibonacci.java` | Gera os 10 primeiros termos da sequência de Fibonacci |
| `Tabuada.java` | Exibe a tabuada do 1 ao 10 |
| `NumeroPrimo.java` | Verifica se um número é primo |
| `InvestigacaoCrime.java` | Versão alternativa do interrogatório (com `nextLine`) |
| `Main.java` + `Pessoa.java` | Demonstração de classe, encapsulamento e métodos |
| `Programa.java` + `SequenciaNumeros.java` | Lê vários números, mostra menor, maior e ordenados |

## 🧠 Conceitos

- Métodos estáticos
- Classes e objetos
- Encapsulamento (`private` + getters/setters)
- Arrays
- `Arrays.sort()`
- `for-each`
